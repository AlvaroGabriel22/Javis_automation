# S00 · Base local e primeiro fluxo persistente

O primeiro incremento entrega o painel, a autenticação local, a migração inicial, os contratos HTTP e o fluxo manual de contatos e mensagens agendadas. Usar o fluxo manual permite testar a mesma persistência que depois receberá comandos do WhatsApp. Cada mensagem guarda o destinatário, o conteúdo, a hora planejada e o estado.

## Critérios de conferência

- Gerar um código pelo terminal, entrar no painel e encerrar a sessão.
- Cadastrar um contato e criar uma mensagem em horário local futuro. Repetir a mesma requisição com a mesma chave e verificar que existe apenas um agendamento.
- Reabrir o painel, consultar os dados e cancelar o agendamento.
- Tentar entrar com um código já consumido, gravar sem token CSRF, usar horário sem fuso e reaproveitar chave com outro conteúdo. Verificar que o erro tem um código estável.
- Executar os testes nos perfis SQLite e PostgreSQL e a jornada Chromium antes de declarar homologação da S00 no host de uso.

## Verificação deste incremento

| Verificação | Resultado observado |
|---|---|
| Suíte HTTP e persistência com SQLite | 14 testes aprovados. |
| Conversão de data e hora no frontend | 3 testes aprovados, incluindo virada de ano e data inválida. |
| Análise estática e build | Ruff, Pyright, TypeScript e build Vite concluídos. |
| Integração da aplicação | O painel React compilado foi exercitado em DOM simulado contra a API ASGI real e SQLite. Login, contato, gravação, recarga, cancelamento e logout passaram. |
| PostgreSQL 16 | Migração e releitura de registro verificadas em modo de usuário único. A conexão por socket e a suíte pelo driver fazem parte da homologação em CI ou no host. |
| Navegador Chromium | A jornada Playwright está incluída. O ambiente de desenvolvimento bloqueou a inicialização do navegador por permissão de socket; a execução real segue pendente. |
